Unit Test :
-----------

Unit testing is a software testing technique where individual units or components 
of a software application are tested in isolation to ensure that they function as expected.
The primary goal of unit testing is to validate that each unit of the software performs as designed,
which helps in identifying and fixing bugs early in the development process.

Remarks:
Write a test for each method in the controller and each possible scenario!
examples:

Test if the method returns the correct student when a VALID ID is provided:
GetAsynById_ShallReturnStudentWithId_ForExistingStudentWithId()

Test if the method returns the correct student when a INVALID ID is provided:
GetAsynById_ShallReturnNotFoundResult_WhenStudentNotFound()
GetAsynById_ShallReturnBadRequest_WhenStudentIdEqualsZero()

Project Reference
